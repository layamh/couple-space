## 2. 重构目标与用户体验

### 2.1 产品目标

1. **摆脱简陋感**：用成套 AI 精致插画与日系治愈场景替代简笔画，使宠物页成为 App 的视觉亮点。
2. **补齐"可长期玩"的养成闭环**：从"点几下按钮"升级为"收割→喂养→互动→旅行→收集→装扮"的循环，佛系节奏、不打扰也能自己玩。
3. **强化情侣共养的陪伴感**：双方共同照顾、共同收到明信片、共享互动记录，让宠物成为两人关系的见证物。

### 2.2 目标用户体验（用户故事）

| # | 用户故事 |
| --- | --- |
| 1 | 作为情侣一方，我希望看到一只精致可爱的青蛙在日式小院里看书/睡觉，以便获得治愈放松的感受。 |
| 2 | 作为情侣一方，我希望给宠物准备便当和护身符后让它出门旅行，以便收到它寄回的明信片和土特产。 |
| 3 | 作为情侣一方，我希望用三叶草购买家具、服饰并布置小窝，以便打造属于我们两人的专属小家。 |
| 4 | 作为情侣一方，我希望看到伴侣照顾宠物的记录和共同收集的明信片，以便感受到"一起养"的陪伴。 |
| 5 | 作为用户，我希望随着等级和亲密度提升解锁新装饰，以便有长期养成的目标感。 |

### 2.3 核心体验循环

```
收割三叶草 → 购买便当/装饰 → 日常喂食互动（涨经验/亲密）
      ↑                              ↓
   明信片/土特产 ← 旅行归来 ← 备行囊出门 ← 布置小窝/换装（涨心情）
```

## 3. 宠物设定与画风定义

### 3.1 宠物设定决策（重要）

**决策：改为「圆润可爱的青蛙」，名字可自定义，默认名延续「布丁」。**

| 决策项 | 结论 | 理由 |
| --- | --- | --- |
| 物种 | **青蛙（frog）**，替代原猫咪 | 与旅行青蛙的治愈画风、旅行玩法天然契合；圆润青蛙造型更容易做出"佛系呆萌"的表情包式立绘；用户明确倾向青蛙。 |
| 默认名 | **布丁**（可随时改名，保留原 `rename` 能力） | 延续原 App 的可爱命名资产，降低老用户认知成本；新用户可自由自定义。 |
| 成长阶段 | 蛋 → 幼年 → 少年 → 成年（沿用 `egg/baby/teen/adult` 枚举） | 与原数据结构兼容；蛋期保留"破壳"仪式感。 |
| 性格 | 安静、佛系、偶尔呆萌；在家自己看书/吃饭/睡觉/写信 | 还原旅行青蛙"不打扰也能自己玩"的气质。 |

> 架构师注意：`pets.species` 默认值由 `cat` 改为 `frog`；`name` 默认值由 `小甜心` 改为 `布丁`（见第 10 节数据迁移）。

### 3.2 画风定义（AI 生成统一规范）

> 以下为**成套风格的硬性要求**，所有素材必须遵守，确保跨批次生成像"同一套绘本"。

| 维度 | 要求 |
| --- | --- |
| 风格定位 | 日系治愈系**水彩手绘绘本**，旅行青蛙同款安静、温暖、生活感；避免写实、避免卡通描边动画风 |
| 色调 | **低饱和、高明度暖色**：奶油白 `#FFF6E9`、暖粉 `#F7C8D8`、薄荷绿 `#BFE3CF`、暖杏 `#FFD9A8`、浅木棕 `#D9B38C`；禁止荧光色与高对比 |
| 线条 | 圆润无硬边；**无描边或 1–2px 暖灰细描边**（参考 `#7A6A63`）；不用黑色粗描边 |
| 质感 | 水彩晕染 + 轻微纸张颗粒纹理，边缘柔和过渡 |
| 光源/阴影 | 统一**左上柔光**，柔和弥散投影，禁止生硬黑影 |
| 视角 | 角色 **3/4 正面视角**；场景轻微俯视 2.5D；明信片正面平视 |
| 留白 | 角色/物件**透明底**，主体居中占画面 60–70%，四周≥10% 留白，便于叠加 UI 与互动动效 |
| 角色一致性 | 统一五官（圆眼、椭圆小腮红、浅笑弧线嘴）、2–3 头身比例、统一体色；跨所有立绘/服饰严格一致 |
| 情绪 | 表情克制温和，呆萌不夸张；整体传达"佛系治愈" |

### 3.3 画布规格（统一）

| 素材类型 | 规格 | 格式 |
| --- | --- | --- |
| 角色立绘 | 1024×1024，透明底 | PNG |
| 服饰配件 | 1024×1024，透明底，与角色同锚点/比例（可叠加） | PNG |
| 场景背景 | 1080×1440（3:4 竖版），UI 用 `object-fit: cover` 裁切 | PNG/JPG |
| 家具摆件 | 512×512，透明底 | PNG |
| 明信片 | 1280×960（4:3 横版），带手绘留白边框 | JPG |
| 道具/三叶草 | 512×512，透明底 | PNG |

## 4. 养成系统需求

### 4.1 数值体系（表格）

| 属性 | 范围 | 初始值 | 变化规则 | 说明 |
| --- | --- | --- | --- | --- |
| 等级 `level` | 1–10 | 1 | 经验达阈值自动升级：`升级所需 exp = (level-1)×100` | 驱动装饰解锁 |
| 经验 `exp` | 0–900+ | 0 | 喂食 +10、陪玩 +8、摸摸 +5、旅行归来 +30 | 累计值，满级后不再增长 |
| 心情 `mood` | 0–100 | 70 | 互动 +5~12；**每小时自然 -2**；旅行中不衰减 | 影响立绘表情/状态 |
| 饱食 `fullness` | 0–100 | 60 | 喂食 +25；**每小时自然 -4**；旅行中不衰减 | 低于 20 提示"它饿了" |
| 亲密度 `intimacy` | 0–100 | 0 | **双方每日各首次互动 +2**、共同完成一次旅行 +10 | 共享值，驱动装饰解锁 |
| 三叶草 `clovers` | 0–999 | 10 | 收割 +2/株、旅行归来 +5~15、购买 -价 | 商店货币 |
| 成长阶段 `stage` | egg/baby/teen/adult | egg | 由等级映射：L1=蛋、L2–3=幼年、L4–6=少年、L7–10=成年 | 换对应立绘 |

**防刷规则**：陪玩/摸摸无消耗，但**同一用户对同一宠物每种互动 30 分钟内只计一次数值收益**；喂食需消耗 1 份便当（饱食 = 100 时不可喂）。

**自然衰减**：以 `last_decay_at` 为基准按小时补算 mood/fullness，下限 0；旅行期间（`is_traveling=true`）暂停衰减。佛系节奏，衰减缓慢。

### 4.2 在家状态机（佛系自治）

宠物在家时随机切换状态，**无需用户操作也会自己玩**，仅影响展示立绘与文案，不改变数值：

| 状态 | 展示立绘 | 文案示例 | 切换 |
| --- | --- | --- | --- |
| 看书 reading | 捧书青蛙 | "它在安静地看书…" | 每 15–40 分钟随机切换 |
| 吃饭 eating | 捧碗青蛙 | "吧唧吧唧，吃得真香" | 同上；饱食 <20 时权重提高 |
| 睡觉 sleeping | 趴睡青蛙 | "呼呼…做着甜甜的梦" | 同上；夜间权重提高 |
| 写信 writing | 趴桌写信青蛙 | "它好像在给谁写信呢" | 同上 |
| 发呆 idle | 坐着青蛙 | "呆呆地望着窗外" | 默认兜底 |

### 4.3 旅行流程（Mermaid）

```mermaid
flowchart TD
    A[进入旅行页] --> B{行囊是否备好?}
    B -- 未备好 --> C[选择便当 必选 / 护身符 可选 / 道具 可选]
    C --> B
    B -- 已备好 --> D[点击 出发]
    D --> E[状态置为 旅行中<br/>记录出发与归来时间]
    E --> F[等待 2~8 小时 佛系不打扰<br/>期间暂停数值衰减]
    F --> G[到达归来时间 触发归来]
    G --> H[按便当/护身符品质随机生成<br/>明信片 + 土特产 + 三叶草 + 经验]
    H --> I[明信片入独立图鉴<br/>土特产入库存<br/>亲密度 +10]
    I --> J[宠物状态回到 在家<br/>通知双方"它回来了"]
```

- **归来判定**：采用"预计归来时间戳"，任一情侣打开 App 时若已到点即结算（无需服务端定时器）；演示模式将等待压缩为 **2–5 分钟**便于体验。
- **明信片品质**：普通便当 → 普通明信片池；豪华便当/护身符 → 提高稀有明信片概率（建议稀有权重 15% → 40%）。
- **情侣共养**：旅行由任一方发起，归来**明信片与土特产为 couple 共享**，双方均收到通知；互动记录写入共享的 `pet_interactions`。

## 5. 装饰系统需求

### 5.1 ① 宠物小窝布置（家具摆放）

- 在庭院/房间场景中以"自由拖拽 + 网格吸附"摆放家具：小床、玩具、地毯、绿植、书架、灯笼、茶几、秋千等。
- 每件家具可**移动、旋转（左右镜像）、收起**；摆放位置以归一化坐标 `x/y (0~1)` 存储，双方实时同步。
- 场景内家具数量上限建议 12 件；点击家具可预览名称与"收起"。
- 验收：拖拽后位置刷新不丢失，伴侣端实时看到位置变化。

### 5.2 ② 宠物穿搭换装（服饰）

- 服饰分类：帽子、围巾、蝴蝶结、眼镜等；每类可**多选互斥**（一个部位同时只穿一件），点击穿上/脱下。
- 服饰以透明 PNG 叠加在角色立绘同锚点上，**立即预览**；穿上后宠物页、旅行归来图均展示。
- 验收：换装后立绘正确叠加、无错位；点击已穿服饰可脱下。

### 5.3 ③ 场景背景切换

- 提供多套主题背景：**庭院小窝（默认）/ 卧室 / 花园 / 星空 / 海边**；点击即切换，整页场景即时生效。
- 背景与家具、宠物立绘为独立图层，切换背景不影响已摆放家具（家具随场景保留）。
- 验收：5 套背景可切换且按解锁条件可见；切换后刷新保持。

### 5.4 ④ 养成解锁装饰

- 家具与服饰默认**锁定**，达到等级/亲密度阈值后解锁并显示"可购买"，未解锁显示锁定态与条件提示。
- 解锁后仍需用三叶草购买/领取才入库（见第 6 节）。
- **解锁条件表**（示例，架构师可按此建 catalog）：

| 装饰 | 类别 | 解锁条件 | 价格（三叶草） |
| --- | --- | --- | --- |
| 草帽 | 服饰 | 初始拥有 | 0 |
| 小木床 | 家具 | 初始拥有 | 0 |
| 蝴蝶结 | 服饰 | 亲密度 ≥ 20 | 20 |
| 毛线地毯 | 家具 | 等级 ≥ 2 | 25 |
| 针织围巾 | 服饰 | 等级 ≥ 3 | 30 |
| 绿植盆栽 | 家具 | 亲密度 ≥ 30 | 30 |
| 圆框眼镜 | 服饰 | 等级 ≥ 4 | 35 |
| 小书架 | 家具 | 等级 ≥ 5 | 50 |
| 星星灯 | 家具 | 亲密度 ≥ 50 | 55 |
| 星空背景 | 背景 | 等级 ≥ 6 | 60 |
| 海边背景 | 背景 | 亲密度 ≥ 60 | 60 |
| 花园背景 | 背景 | 等级 ≥ 8 | 70 |

> 注：上表为 catalog 子集，完整清单以第 9 节 AI 素材清单（服饰 8 / 家具 8 / 背景 5）为准；未列项默认"等级 ≥ 3 或亲密度 ≥ 30"解锁，价格 20–60。

## 6. 三叶草经济与商店

### 6.1 三叶草产出

| 来源 | 规则 |
| --- | --- |
| 庭院种植 | 三叶草丛**每 30 分钟生长 1 株，上限 8 株**；点击收割，每株 +2 三叶草 |
| 旅行归来 | 固定 +5~15 三叶草（随便当品质浮动） |
| 土特产兑换 | 土特产可兑换 +5 三叶草，或保留收藏 |

### 6.2 商店商品

| 商品 | 类型 | 价格（三叶草） | 作用 |
| --- | --- | --- | --- |
| 普通便当 | 消耗品 | 3 | 喂食 +25 饱食；旅行行囊（普通明信片池） |
| 豪华便当 | 消耗品 | 8 | 旅行行囊，提高稀有明信片概率 |
| 护身符 | 消耗品 | 15 | 旅行可选道具，再提高稀有概率 |
| 家具/服饰 | 装饰品 | 20–70 | 按解锁条件购买，入库后可摆放/穿搭 |

- 商店按"消耗品 / 家具 / 服饰 / 背景"分区；未解锁商品显示锁定态。
- 初始赠送 **10 三叶草** 与 **1 份普通便当**，保证首日可完成一次喂食或旅行。
